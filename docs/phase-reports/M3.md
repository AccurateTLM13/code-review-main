Environment notes captured during the run (all known quirks, now with exact fixes recorded):
- `git clone E:\code\…` fails — git parses the drive letter as an scp-style host; the working form is `git clone file:///E:/code/…`.
- "dubious ownership" fires for `E:/code/code-review-main/.git` even when the parent is in `safe.directory` — the `.git` path needs its own `safe.directory` entry (added).
